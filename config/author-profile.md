# 作者档案

**这是署名、简介、CTA 的唯一来源。** 写作阶段和排版阶段都从这里取，不许各写各的，更不许自己编一个名字。

`{{ }}` 是占位符。**没填的字段保留占位符原样交付，并在交付清单里提醒用户替换**——绝对不要猜一个填进去。

## 身份

| 字段 | 值 |
|------|-----|
| 署名 | `{{作者名}}` |
| 公众号名 | `{{公众号名}}` |
| 一句话简介 | `{{一句话简介，例：热衷于分享 AI 观察与踩坑记录}}` |
| 投稿 / 联系方式 | `{{邮箱或留空}}` |
| 星标引导 | `{{是否需要，默认需要}}` |

## 尾部模板

写作阶段把这段放在正文最后，排版阶段把它并入唯一的签名卡，不另起一个。

```
以上，既然看到这里了，如果觉得不错，随手点个赞、在看、转发三连吧，如果想第一时间收到推送，也可以给我个星标⭐～

谢谢你看我的文章，我们，下次再见。

/ 作者：{{作者名}}
/ 投稿或爆料，请联系邮箱：{{邮箱}}
```

排版阶段的签名卡第一句用：`我是 {{作者名}}，{{一句话简介}}`

| 类别 | 词 |
|------|-----|
| 转场 | `{{留空则用通用词库}}` |
| 表达判断 | `{{留空则用通用词库}}` |
| 自嘲 / 承认不足 | `{{留空则用通用词库}}` |

## 禁忌

除了 khazix preset 的通用禁区（套话、冒号破折号双引号、假设性例子、空泛工具名）之外，本账号额外不写的东西：

- `{{例：不碰政治话题 / 不做未实测的产品推荐 / 不用某某词}}`

## 内容边界

- 选题必须过 HKR 质检，只占一项就跟用户重新对方向。
- 第一手观察、真实经历、个人判断只能来自用户，AI 不许代笔编造。
