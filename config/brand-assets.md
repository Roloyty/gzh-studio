## 路线判定

按上面填了什么决定走哪条，**不要问用户第二遍**：

| 配置状态 | 走法 |
|---------|------|
| 头像 / IP / Logo 至少填了一项 | 那些填了的当作必须出现的品牌元素。手法参照 `vendor/cover-skill/references/personal-brand.md`（形象一致性、正中构图、文字与主体的景深关系、Logo 确定性合成），形象换成这里配的 |
| 只填了配色 / 字体 | 品牌层只体现在色彩和字形上，不放人像和吉祥物 |
| 全是占位符 | **跳过 personal-brand 的全部强制项**，走纯文字 + 图形封面。仍保留 `core-rules.md` 的质量红线和 `qa.md` 的验收 |

## 不变量

无论走哪条路线，这些照 cover-skill 原样保留：

- 公众号封面锁 **21:9（2100×900）**。
- 标题和摘要**逐字**来自阶段 3，标点空格英文大小写都不改。
- 四概念探索 → 用户选一 → 五比例适配，两段式不省。
- 中文文字、数字、真实 Logo 用确定性合成（Pillow / SVG / HTML 渲染）。图像模型只画场景、氛围、材质、背景扩展。
- 每张导出图都要实际看过再报 PASS，manifest 布尔值不算数。
- 未经用户明确要求，不发布不上传任何封面。

## 没有图像生成工具时

不要假装生成。走纯合成降级路线：HTML/SVG 排一版 21:9 文字封面（标题 + 摘要 + 品牌色块 + Logo），照跑四概念选一和 QA，并明确告诉用户这是降级方案。
本机可用的图像能力可以先看 `bailian-cli` skill，或 kangarooking 的 `apimart-image-gen`。
